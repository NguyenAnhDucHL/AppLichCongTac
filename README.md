# 📅 Ứng dụng Lịch Công Tác - UBND Phường Cẩm Phả

Ứng dụng quản lý lịch công tác với hệ thống admin hoàn chỉnh.

## 🚀 Quick Start

```bash
# Cài đặt dependencies
npm install

# Setup database
node scripts/setupDatabase.js

# Chạy development
npm start

# Deploy web app
./deploy-web-app.sh
```
